# Scoped explorer publication review

This review concerns the exact structured annotation snapshot and static explorer identified in publication.json. It is separate from the unresolved review of the full archived extraction texts. The original archive is unchanged and remains private.

## Included material and basis

The original program code, explanations, annotation decisions and derived network data are distributed under the author's MIT/CC BY 4.0 grants, with third-party exclusions. Source-derived fields are factual actor names, short office/affiliation labels, document metadata and mechanical provenance coordinates. They carry official document identifiers rather than reproduced narrative passages.

The inventory found 1,209 occurrence rows across L/A/R, 630 normalized claims, 594 actor/report attribute rows and 606 saved intervention records. Actor/mention strings are at most eight words; office literals at most sixteen; affiliation literals at most seven. These bounds describe the inspected data; word count alone is not a rights determination. The downloadable data contains no full paragraphs, complete sentence prose, annex statements, narrative model reasons, private journals, raw inference calls or credentials.

The publication rationale is the separation between factual information/short identifiers and the source author's narrative expression. The [U.S. Copyright Office guidance](https://www.copyright.gov/help/faq/faq-protect.html) explains that facts, names and short titles are not protected by copyright, while original expression may be. This is a documented basis for the limited factual/analytical export, not a blanket legal clearance, UN permission letter or determination under every jurisdiction. Project licenses apply only to the author's own contributions.

The public glossary supplies newly written short explanations for CAMEO identifiers. It excludes the previous imported/adapted definition strings and does not distribute the CAMEO manual. The original code assignments and scientific fields are unchanged. The [manual](https://github.com/openeventdata/Dictionaries/blob/master/CAMEO.Manual.1.1b3.tex) is linked for attribution and full context.

## Excluded material and unresolved matters

Full extracted report texts, annex contributions, manuscript sources/PDFs, private review journals, session/participant records, model assets, proprietary fonts and inference logs are excluded from this repository and Pages artifact. The source archive's unresolved attributed material in S/2004/428 and S/2017/282 is not cleared by this review. It must not be copied into a later website build. No source bytes were altered or removed from the scientific archive to bypass reconstruction checks.

Official UN URLs remain links to external source documents. Optional source text selected by a visitor is verified and displayed only in that visitor's browser; it is neither bundled nor uploaded. Publication of another mission's data requires a separate review; compatible format validation does not supply one.

## Mechanical checks and approval

The scientific collections are compared exactly with the verified upstream bundle. Every deployed file is allowlisted and hash-checked; the annotation ZIP must contain the same rows as the visible explorer. The independent JavaScript projector reconstructs all six published networks with isolates and exact weights. Optional local-text tests verify Unicode codepoint offsets.

publication.json records the reviewed bundle hash, scientific-data hash, upstream commit, scope and author authorization status. Deployment requires authorization plus passing checks. The full research repository remains private, and this publication does not create a manuscript release or a public exact-source archive.
